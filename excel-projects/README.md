## 🚀 How to Use These Files

1. Clone or download this repository
2. Open any `.xlsx` file in **Excel 365** (dynamic array functions require 365/2021+)
3. Each workbook is self-contained with labeled sheets and inline notes

> ⚠️ Some features (LAMBDA, FILTER, dynamic arrays) require **Excel 365** or **Excel 2021**. Older versions may display `#NAME?` or `#SPILL!` errors.
